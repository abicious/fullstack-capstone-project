# User Story

**As a** user who wants to give away household items,  
**I want to** post an item listing with a description and category,  
**So that** other users can find and claim it instead of buying new ones.

### Acceptance Criteria
- [ ] User can input item name, description, and category.
- [ ] Listing is saved securely to the MongoDB database.
- [ ] Item appears instantly on the main page feed.
